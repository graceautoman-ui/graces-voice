连接 Obsidian

新版 1.1.2 支持直接选择笔记并返回。需要 Obsidian 1.9.10 或更新版本；安装旧版插件的用户请重新下载，用新包替换插件文件夹内的 main.js 和 manifest.json，关闭再开启插件。

1. 安装一次插件

下载 Grace Existing Append 并解压。

在 Mac 上找到你正在使用的 Obsidian 库，把解压后的 grace-existing-append 文件夹放入库的 .obsidian/plugins/ 下。文件夹内应直接包含 main.js 和 manifest.json。

Finder 按 Command + Shift + . 显示隐藏文件。重新打开 Obsidian，在「设置 → 第三方插件」启用 Grace Existing Append。

iPhone 打开同一个 iCloud 库，等插件文件夹同步后，在第三方插件中单独启用。如果尚未出现，请检查该库的 .obsidian 配置文件夹是否已同步。不要修改日常笔记内容。

本应用不再通过 Advanced URI 写入；不需要卸载你原有的插件。如果装过 Grace 测试插件，关闭它后用本包替换同名文件夹里的两个文件，重启并启用即可。

2. 直接选择已有笔记

先在 Obsidian 创建用于接收记录的 Markdown 文件。

在 Grace‘s Voice 的「分类」中新增一级分类 → 新增二级分类，输入名称，点击「去 Obsidian 选择笔记」。

Obsidian 会显示已有笔记列表。选中后会尝试返回网页，自动填入目标。点击「保存」完成绑定，不需要复制配置。

如果系统没有返回，可点击 Obsidian 中的「返回 Grace」。如果返回到另一个浏览器或 Safari，而非原主屏幕应用：点击「复制返回链接」，回到原应用，选择「继续配置目标笔记」→「取回选择结果」，粘贴链接取回。

首次未设置 Vault 时，会在 Obsidian 当前打开的库中选择；以后使用设置中的 Vault。取消选择不会改变映射，也不会写入笔记。选择请求有效期为 30 分钟。

旧版插件暂未更新时，可展开「兼容旧插件：粘贴配置」沿用原方式。

Mac 配置导入手机

Mac「设置 → 导出分类配置」，把 JSON 文件通过 AirDrop 或 iCloud Drive 传到手机。手机打开 Grace「设置 → 导入分类配置」，选择文件并确认。

只包含 Vault、分类和映射，不含正文、草稿或历史。相同 ID 更新、其他分类保留；同名但不同 ID 的分类会提示冲突。导入不会安装手机插件，手机仍需启用 Grace Existing Append。

3. 直接开始记录

写正文，选择两级分类，保存。应用先保存本地历史，再尝试打开 Obsidian。系统可能要求确认打开应用。

若未出现记录，先核对笔记及插件；修正配置后，从历史重新写入。重新写入使用最新映射，保留原文和创建时间，可能产生重复内容。

iPhone Safari 分享 → 添加到主屏幕。首次联网打开并缓存完成后可离线记录。重新打开应用可获取已发布更新。

“已发起写入”不等于写入或 iCloud 同步成功。文件不存在时插件拒绝追加；不会建文件。避免跨设备同时编辑同一目标。
